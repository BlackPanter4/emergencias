# 🚨 Emergencias Luchanas - Ciudad Juárez

Plataforma web de respuesta rápida para reportar emergencias en tiempo real en Ciudad Juárez.

🔗 **Live Demo:** https://blackpanter4.github.io/emergencias/
📱 **Optimizada para Android - Moto G05 y cualquier celular**

## 🚀 Stack
- **Frontend:** HTML5, CSS3, JavaScript Vanilla
- **Maps:** Leaflet.js + OpenStreetMap
- **APIs:** Geolocation API, WhatsApp API, Google Maps Links
- **Deploy:** GitHub Pages - CI/CD automático

## ✨ Features
- 📍 Reporte con pin en mapa interactivo
- 📲 Envío automático a WhatsApp con ubicación exacta
- 🛰️ Mi Ubicación con GPS en tiempo real
- ⚡ PWA ready, mobile-first, sin instalación
